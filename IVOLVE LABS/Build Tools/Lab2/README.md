# Lab 2: Gradle Calculator App

## How to Run

1. Navigate to project folder:
   ```bash
   cd ~/CalculatorGradleApp
   ```

2. Clean and build the project:
   ```bash
   gradle clean build
   ```

3. Run the application:
   ```bash
   java -jar build/libs/CalculatorGradleApp-1.0-SNAPSHOT.jar
   ```
